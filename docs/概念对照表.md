# 概念对照表

速查：约束 ↔ optic ↔ 张量。叙事见 [学习路线.md](学习路线.md)，推理见 [原理详解.md](原理详解.md)。

## 约束与 optic

| 我们的约束 | Optic | 张量 / 强度 | 直觉 | 库中常见名 |
|------------|-------|-------------|------|------------|
| `Profunctor` | **Iso** | 无额外强度（可逆 dimap） | 整树可逆重写 | `Iso` |
| `Strong` / `Tambara (,)` | **Lens** | 积 `(,)` | 焦点总在；上下文平行 | `Lens` |
| `Choice` / `Tambara Either` | **Prism** | 和 `Either` | 焦点可能没有 | `Prism` |
| `Strong` + `Choice` | **Affine** | 可选积 | 至多一个焦点 | `AffineTraversal` / `Optional` |
| `Traversing` / `Wander` | **Traversal** | traversable 强度 | 零或多个焦点 | `Traversal` |

编码形状（profunctor optic）：

```haskell
type Iso   s t a b = forall p. Profunctor p          => p a b -> p s t
type Lens  s t a b = forall p. Strong p              => p a b -> p s t
type Prism s t a b = forall p. Choice p              => p a b -> p s t
type Affine s t a b = forall p. (Strong p, Choice p) => p a b -> p s t
-- Traversal: forall p. Traversing p => ...
```

## Tambara 一览

| 说法 | 积 `(,)` | 和 `Either` |
|------|----------|-------------|
| 强度 α | `p a b → p (c,a) (c,b)`（≈ `second'`） | `p a b → p (Either c a) (Either c b)`（≈ `right'`） |
| 经典类 | `Strong` | `Choice` |
| optic | Lens | Prism |
| existential | `∃c. (s→(c,a)) × ((c,b)→t)` | `∃c. (s→Either c a) × (Either c b→t)` |
